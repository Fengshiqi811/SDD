\# 智能日报生成器 - 前端设计规范（SDD v1.0）

\## 1 概述

本文档为「智能日报生成器」前端可视化页面的 \*\*Spec-Driven-Design 官方规范\*\*。

所有前端页面、UI 组件、交互逻辑、接口定义、异常状态、验收标准，\*\*全部以本文档为唯一标准\*\*。



前端目标：对后端已生成的日报数据做可视化展示、筛选、预览与导出，基于 OpenDesign 组件库统一视觉与交互。



\## 2 技术栈约束

\- 前端框架：Vue3

\- UI 组件：OpenDesign（TinyVue）全套官方组件，禁止自定义原生样式覆盖

\- 数据渲染：Markdown / HTML 双模式渲染

\- 网络请求：Axios

\- 构建工具：Vite



\## 3 页面整体结构（唯一页面）

页面名称：PageDailyReport（日报主页）



页面固定四分区：

1\. \*\*顶部操作栏\*\*：页面标题、刷新、导出、复制按钮

2\. \*\*筛选控制区\*\*：日期选择、团队成员筛选

3\. \*\*原始数据区（左）\*\*：展示今日采集明细

&#x20;  - GitHub Commit 记录

&#x20;  - 飞书任务变更记录

&#x20;  - 飞书关键词消息记录

4\. \*\*日报成品预览区（右）\*\*：渲染最终 Markdown/HTML 日报



\## 4 页面组件清单（全部使用 OpenDesign 原生组件）

1\. DatePicker 日期选择器

2\. Select 成员多选下拉框

3\. Button 操作按钮组

4\. Card 数据卡片容器

5\. Table 原始数据表格

6\. Alert 错误/空状态提示

7\. Loading 全局加载状态

8\. Markdown 预览面板



\## 5 接口契约（前后端唯一对接标准）

\### 请求地址

`GET /api/report`



\### 请求参数（Query）

\- date: string（YYYY-MM-DD）必填

\- members: array\[string] 可选



\### 返回结构

```json

{

&#x20; "code": 0,

&#x20; "data": {

&#x20;   "raw\_records": {

&#x20;     "github": \[],

&#x20;     "lark\_task": \[],

&#x20;     "lark\_msg": \[]

&#x20;   },

&#x20;   "report\_markdown": "string",

&#x20;   "report\_html": "string",

&#x20;   "meta": {

&#x20;     "collect\_count": 0,

&#x20;     "errors": \[]

&#x20;   }

&#x20; }

}

\## 6 交互规范（强制统一）

1\. 切换日期 / 切换成员 → \*\*自动重请求、自动弹出 loading\*\*

2\. meta.errors 不为空 → 页面顶部展示「部分数据源获取失败」

3\. 所有数据为空 → 预览区展示「今日无记录」

4\. 请求超时 / 500 → 展示「数据加载失败，请重试」

5\. 刷新按钮：手动重新拉取一次全量数据

6\. 复制按钮：复制 report\_markdown 到剪贴板

7\. 导出按钮：下载完整 HTML 日报文件



\## 7 状态规范（三种固定状态）

\- \*\*正常状态\*\*：展示左右两区完整数据

\- \*\*空数据状态\*\*：无任何采集记录

\- \*\*异常降级状态\*\*：部分/全部数据源失败，但页面不崩溃



\## 8 视觉与布局规范（给 OpenDesign AI 专用）

\- 布局：经典左右分栏、自适应大屏

\- 主色：OpenDesign 默认主题蓝

\- 成功：绿色、警告：黄色、错误：红色

\- 卡片圆角统一、间距统一、按钮尺寸统一

\- 全部采用官方组件默认交互 hover / disable / active 状态



\## 9 非功能约束

\- 页面加载超时：8秒

\- 响应式：优先桌面端，适配1920/1080

\- 所有UI无硬编码样式，全部依赖 OpenDesign 主题变量

\## 10 验收标准（前端可上线标准）

\- \[ ] 页面结构完全匹配四区布局

\- \[ ] 所有组件均使用原生 OpenDesign 组件，无手写DOM样式

\- \[ ] 日期筛选、成员筛选可正常请求后端接口

\- \[ ] 成功、空数据、报错三种状态展示完全符合规范

\- \[ ] 刷新、复制、导出功能可用

\- \[ ] 加载状态流畅不闪烁

\- \[ ] 与 OpenDesign 设计稿视觉1:1还原

\- \[ ] 前端无控制台报错
