高保真可交互原型

对齐后端采集 / 生成 / 存储 / 推送能力。主路径：浏览列表 → 打开详情 → 生成日报 → 返回列表。 字段与缺口见 UI_SPEC.md，视觉见 DESIGN-SYSTEM.md。

1 日报列表 筛选、分页、空态 / 加载 / 错误 / 无权限演示。对应 ReportStorage.list_reports。 2 日报详情 采集明细（Commit / Task / Message）+ Markdown 成品；复制、导出、推送确认、删除。 3 生成日报 创建表单。对接现网 POST /api/report（date、member）；可切换真实后端联调。

交付物

  • DESIGN-SYSTEM.md — 色板 / 字体 / 间距 / 组件
  • UI_SPEC.md — 页面清单、字段↔API、缺口
  • report-*.html + assets/prototype.* — 可预览源码
  • 旧版 components.html 组件清单可作对照（视觉已迭代）
